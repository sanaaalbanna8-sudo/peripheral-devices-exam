امتحان ختامي — الأجهزة الطرفية والوسائط
========================================

افتحي index.html في المتصفح.
المحتوى مطابق لدرس معرض الأجهزة الطرفية (لا أسئلة من خارج صفحة الشرح).

المدة: 55 دقيقة ثم تسليم تلقائي.
الدرجة الكاملة: 52 (20 تصنيف + 32 فهم).

الجزء الأول — تصنيف (سحب وإفلات)
--------------------------------
20 جهازًا تُخلط لكل طالب، تُوزَّع على خمسة صناديق:
إدخال / إخراج / تخزين ووسائط / اتصال / إمكانية وصول.

يمكن السحب بالماوس أو الضغط على البطاقة ثم الصندوق (للأجهزة اللوحية).
درجة لكل تصنيف صحيح. البنود غير الموضوعة = صفر.
بعد المتابعة لا يُعاد فتح التصنيف.

ملاحظة تصميم: شاشات اللمس لم تُدرج في السحب لأنها مزدوجة الدلالة في الدرس
(إدخال أساسًا، وتفيد إمكانية الوصول). يظهر السؤال عنها في الجزء الثاني.
فلاش USB = تخزين. معيار USB = اتصال.

الجزء الثاني — فهم (أسئلة مخلوطة)
--------------------------------
20 سؤالًا: صور، صح/خطأ، اختيار من متعدد، وسيناريوهات شراء للمؤسسة.
الترتيب والخيارات يُخلطان لكل طالب (عدا صح/خطأ).

حفظ النتائج في Google Sheets
----------------------------
1) أنشئ جدولًا جديدًا لهذا الامتحان فقط (لا تخلطيه مع امتحان الأجهزة الرقمية).
2) Extensions → Apps Script
3) الصقي محتوى google-apps-script.gs
4) ضعي معرف الجدول في SHEET_ID داخل السكربت
5) نشر → نشر جديد → تطبيق ويب
   التنفيذ: أنا
   من يمكنه الوصول: أي شخص
6) انسخي رابط الويب أب (ينتهي بـ /exec) والصقيه في js/config.js داخل sheetsUrl
7) إذا عدّلتِ السكربت لاحقًا: نشر → إدارة عمليات النشر → تعديل → إصدار جديد
